name: csv
summary: A sortable table from CSV or TSV rows (the first row is the header).
aliases: tsv, table, data-table
order: 66
---
```csv
element,symbol,atomic number
Hydrogen,H,1
Helium,He,2
Lithium,Li,3
```

Comma- or tab-separated; quote a cell that has commas (`"1,000"`). Clicking a header sorts by it (numbers as numbers). Up to 1,000 rows are shown. For a handful of rows a Markdown table reads as well.
